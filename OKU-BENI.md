# Kurulum (Netlify)

NOT: Sürükle-bırak yöntemi fonksiyonları (sunucu kısmını) çalıştırmaz. GitHub ile kurun:

1. github.com'da yeni bir depo (repo) açın, bu klasörün içindekileri yükleyin.
2. Netlify > Add new site > Import an existing project > GitHub'dan depoyu seçin > Deploy.
3. Site settings > Environment variables > ADMIN_PIN adıyla yönetici şifrenizi girin.
4. Deploys > Trigger deploy ile tekrar yayınlayın.
5. Siteyi açın > "Yönetici" sekmesi > şifre ile girin > çalışanları ekleyin.
6. Çalışanlar siteyi telefonda açıp isim + şifre ile giriş yapar. "Ana ekrana ekle" ile uygulama gibi kullanılır.

Saat bilgisi sunucudan alınır; çalışan telefon saatini değiştirse de kaydı etkilemez.
